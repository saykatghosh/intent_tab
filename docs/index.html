Two minutes

Install Intent Tab

It’s coming to the Chrome Web Store. Until then, install it in Chrome’s developer mode. It works exactly the same.

Download intent-tab.zip

  1. Unzip the downloaded file (right-click → Extract All…).

    Keep the folder somewhere permanent, such as Documents. Chrome loads it from there.

  2. Open chrome://extensions in Chrome.

    Type it into the address bar and press Enter.

  3. Turn on Developer mode with the switch in the top right corner.

  4. Click Load unpacked and choose the unzipped folder (the one with manifest.json inside).

  5. Open a new tab. If Chrome asks whether to keep the new tab page, choose Keep it.

    Tip: to hide Chrome’s bar under the page, click Customize Chrome → Footer → turn off Show footer.

  1. ডাউনলোড করা ফাইলটা আনজিপ করুন (রাইট ক্লিক → Extract All…)।

    ফোল্ডারটা স্থায়ী কোনো জায়গায় রাখুন, যেমন Documents-এ। Chrome ওখান থেকেই চালায়।

  2. Chrome-এ chrome://extensions খুলুন।

    অ্যাড্রেস বারে লিখে Enter চাপুন।

  3. উপরে ডানদিকের সুইচ দিয়ে Developer mode চালু করুন।

  4. Load unpacked চাপুন, তারপর আনজিপ করা ফোল্ডারটা (যেটার ভেতরে manifest.json আছে) সিলেক্ট করুন।

  5. নতুন ট্যাব খুলুন। Chrome জিজ্ঞেস করলে Keep it চাপুন।

    টিপ: পেজের নিচে Chrome-এর বার লুকাতে Customize Chrome → Footer → Show footer বন্ধ করুন।

Updating: download the new ZIP, replace the old folder’s files, then click ↻ on Intent Tab in chrome://extensions. Your data stays. Also works in Edge, Brave and other Chromium browsers.

Questions

Good to know

Is it really free?

Yes. No account, no subscription and no ads.

Why isn’t it on the Chrome Web Store yet?

It’s on its way. Once it’s there you’ll get one-click install and automatic updates, and this page will link to it. Until then, developer mode works exactly the same.

Will it slow down Chrome?

No. The whole extension is about 240 KB with no frameworks. The background draws its still parts once, runs at a gentle 24 FPS and pauses completely when the tab is hidden or you haven’t touched the page for a minute.

Does the AI send my data anywhere?

No. AI features use Chrome’s built-in on-device model (Gemini Nano). If your device doesn’t support it, simple built-in rules take over, still on your computer.

Will it nag me on every tab?

Only if you want it to. By default it asks after a break of more than 10 minutes. You can choose Always, Work hours or Off, snooze it for an hour or for the day, and Esc always dismisses it.

Does it work in Edge, Brave or Arc?

Yes, in any Chromium-based browser that allows developer-mode extensions. On-device AI depends on the browser.

How do I get rid of the bar under the page?

Chrome adds that bar to every extension’s new tab, and extensions can’t hide it. Click Customize Chrome → Footer → turn off Show footer.
